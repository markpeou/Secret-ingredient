# Spice To Know Ya — Recipe book

Generated by `node scripts/recipe-book.js` from the game data. Edit the data files, not this document.

## How it fits together

1. **Answers → traits.** Each answer quietly adds weight to nine hidden traits (below). Nothing on screen names them.
2. **Traits → spices.** Each spice expresses a few traits. A player’s affinity for a spice is how strongly they lean into those traits, compared with a typical player.
3. **Spices → dish.** Every dish lists its real spices with rough proportions. The dish chosen is the one whose spice set best matches the player’s spice affinities.
4. **Dish → blend.** The blend is built **only from that dish’s spices**. The dish’s usual proportions are tilted towards the spices the player leans into, then rounded to 5% steps that always total 100%.

So the blend always makes culinary sense for the dish, and two people with the same dish can still get different mixes.

## Editing checklist

- Add a spice to `js/data/spices.js`, draw it in `js/ui/characters.js`, and use it in at least one dish.
- Add a dish to `js/data/dishes.js` with only spices that genuinely belong in it (weights sum to 1), and give it art in `js/ui/art.js`.
- Run `node scripts/calibrate.js`, then `npm test`, then `node scripts/recipe-book.js`.
